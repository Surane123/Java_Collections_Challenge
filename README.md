# Java Collections Challenge

An interactive console program demonstrating practical uses of Java collections: ArrayList, HashMap, and a FIFO Queue.

## Features

- Add, remove, update, search, and display tasks in an ArrayList.
- Insert or update student IDs and names, retrieve values by ID, check keys, and list entries with a HashMap.
- Add customers to a service line, serve the next customer, peek at the front, and display the line using a FIFO Queue.
- Validate menu input and handle empty collections and blank text.

## Files

- CollectionsChallenge.java
- Main.java

## Compile and run

Requires JDK 17 or newer. From the repository root, run:

    javac -d out *.java
    java -cp out collections.Main

No external libraries are required.

## Sample menu

    === Java Collections Challenge ===
    1. Manage task list (ArrayList)
    2. Manage student names (HashMap)
    3. Manage service line (Queue)
    4. Exit
